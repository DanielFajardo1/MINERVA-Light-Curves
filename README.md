# MINERVA: Light Curve Visualization Gallery

This repository serves as the visual supplement to the **MINERVA** (Minimum Entropy Variables) catalog. It hosts the folded light curves for all variable stars identified in the b278 and b279 fields of the *VISTA Variables in the Via Lactea* (VVV) Survey.

## Overview
The MINERVA pipeline uses a Joint Bayesian Classifier (CNN + Random Forest) and the Minimum Entropy method to extract and classify stellar variability. This gallery allows researchers to visually inspect the candidates, including on the order of $10^3$ previously unreported variable stars discovered during this work.

## What's Inside the Visual Gallery?
The provided documentation contains folded light curves for all classified sources. Each plot is annotated with:
- **Variability Class:** Suggested classification (e.g., Radial Pulsators (RPs), Eclipsing Binaries (EBs), and Unkown Variables (UVAR)).
- **Subclass:** Detailed distinction (CEP-F, CEP-1OT, RRab, RRc, EA, EW, EBlyr).
- **High-Precision Period:** Derived through the Minimum Entropy framework and validated by binary tests to avoid period-doubling artifacts.

## Data Context
- **Fields:** b278 and b279 (Galactic Bulge).
- **Photometry:** Near-infrared K_s bands from the VVV Survey.

## Purpose
By sharing these visualizations, we aim to provide a transparent resource for the astronomical community to verify the morphological quality of the MINERVA classifications.
